# Notes App

A GUI-based notes application built using Java and MySQL.

This project includes user authentication with signup and login functionality, allowing users to securely store and manage their notes.

---

## Features

- User Signup and Login
- GUI-based Interface
- Create and Save Notes
- MySQL Database Integration
- Simple and User-Friendly Design

---

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
